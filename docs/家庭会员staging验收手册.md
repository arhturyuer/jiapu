# 家庭会员 staging 验收手册

> 文档状态：现行规范。平台配置需每次核验，不能据本文认定已开通；见[文档索引](./文档索引.md)。

## 环境边界

本手册只适用于独立 staging。`youpuUserApi` 与 `youpuJobs` 必须保持 `PAYMENT_MODE=sandbox`，虚拟支付请求固定 `env=1`；`youpuPaymentNotify` 只保留内部调用密钥。只能使用沙箱 OfferID、AppKey、应用凭据和 staging 专用内部密钥，不得填写或复制 production 凭据、数据或域名。开发版小程序是验收入口，沙箱不产生真实资金。

## 部署前检查

1. 按 `deployment/staging-runbook.md` 生成 staging 本地配置并运行 preflight。
2. 部署四个云函数、数据库索引和 deny-all 安全规则；执行 bootstrap 后确认 schema version 为 8。
3. 确认 `payment_orders`、`payment_events`、`membership_grants` 与扩展后的 `export_tasks` 已创建；`commerce_metrics_daily` 已退出活动运行路径，不作为新环境必需集合。
4. 在云开发控制台的“设置 → 其他设置 → 消息推送”中，把 `event/xpay_goods_deliver_notify` 和 `event/xpay_refund_notify` 逐条绑定到 staging 的 `youpuPaymentNotify`，并留存页面截图和函数日志。绑定若会替换 production 目标，必须先获得当前请求的生产授权；不能因 staging 验收而中断生产通知。平台直接向云函数传入 JSON，不配置 HTTP 通知 URL、GET 校验、消息 Token 或 AESKey。每个事件组合同一时间只能绑定一个环境；切换 production 前必须确认 staging 无待确认订单。
5. `youpuJobs` 只保留每日保留期触发器。家庭备份由管理员申请后异步派发；沙箱待确认订单只在用户打开订单并显式重试时以 `env=1` 调用 `query_order`。运营商业指标按打开页面时即时读取，不再周期写入日报集合。
6. 广告开通状态属于待核验的平台事实。家庭、我的及真实与示例家谱人物弹框分别使用 `family`、`profile`、`memberSheet` 广告位；未配置有效广告位 ID 时不应留下广告空白。广告配置以 `miniprogram/config/commerce.js` 和本次平台验收结果为准。开屏为原生模板广告全屏模板，独立使用 `launchAdUnits`；staging/production 均配置已验收 ID，家庭、我的两个 Banner 位仍为空；人物弹框 `memberSheet` 在 staging/production 均配置 `adunit-f0e7fed2bde51c0c`，使用 `ad-custom` Banner 模板，用户确认全部真机验收完成，v1.6.4 已人工上传；本轮补齐配置的 v1.6.5 待人工上传及 production 体验版冒烟；真实家谱顶部独立 `treeTop` 位在 staging/production 均配置已验收 `adunit-48f60f50925b53d9`，使用 `ad-custom` Banner 模板，production 随新客户端生效。
7. 2026-10-04 用户要求去掉后台封面广告；代码中的原生模板开屏保留。人工在微信公众平台“流量主 → 广告管理 → 封面广告”关闭“广告开关”，留存“已关闭”状态后，在 staging 开发版冷启动核对不再先出现平台封面广告。本轮后台连接超时，关闭状态尚未回读；不能通过删除原生模板 ID 代替关闭封面广告。

## 端到端验收

1. 使用虚构测试资料创建家谱 A，并邀请第二个 staging 测试账号加入。另建家谱 B 验证权益不串谱。
2. 在“家庭 → 顶部会员标识”进入家庭会员，确认页面明确显示家谱 A、全体家人共享和不可转移；选择 30 天、1 年或永久 SKU 并阅读说明。
3. 分别选择三个 SKU，完成真机微信沙箱支付。页面应调用 `wx.requestVirtualPayment`，订单保存 `paymentMode=sandbox`、`paymentEnv=1`，最终为 `fulfilled`，且同一订单只有一个 active grant。沙箱真机支付仅使用 Android：微信 Apple IAP 不支持 `env=1` 沙箱，iPhone 开发版应明确拦截并提示改用 Android，禁止为此改用 `env=0`。
4. 分别验证云函数消息推送和用户点击“查单重试”均可完成发货；重复推送、重复查单或重复打开订单不得产生第二个 grant 或延长期限。取消支付、未知事件、错误商品/付款人和订单超时必须不发放权益；处理异常时函数应返回非零结果，让平台重试。
5. 用第二个家庭成员账号打开家谱 A：应能查看完整历史；家谱 B 仍为免费家庭且只能查看最近 20 条。
6. 以家谱 A 管理员生成完整备份。确认请求后立即异步启动，检查退避轮询、进度、分卷不超过 100MB、`manifest.json`、CSV 和审核通过图片；离开页面后不得继续查询。通过“下载并转发”调用 `wx.downloadFile` 与 `wx.shareFileMessage`。非管理员必须被拒绝，7 天内再次申请必须被拒绝。
7. 在沙箱后台触发退款通知并确认订单变为 `refunded`；会员期限按其余未退款 grant 重算。若无有效 grant，完整历史分页、备份和去广告权益立即降级。
8. 打开运营后台“商业化”：核对 GMV、退款、SKU、转化、有效会员家庭和月额度；待确认订单只显示“查单重试”，后台不得出现改价、手工改会员或直接退款入口。
9. staging develop 人物广告统一按当前家谱权益判定，全部家人共享免广告；免费权益确认后预取广告数据，并用不含广告的同样式普通布局槽提前测量像素宽度；首次打开前不创建原生广告。已确认免费时显示广告模块，广告未就绪、无填充、加载失败或 10 秒超时均在广告内容区水平垂直居中显示“广告位，收益用于运营开支”，成功加载后移除文案。模块保留左侧关闭 icon、右侧“开会员，全家人免广告”、至少 200rpx 广告区、固定竖屏 80vh/横屏 100vh 和整体自然高度滚动。提前普通布局测宽、关闭后按平台验收复用、未验证平台销毁兜底、超时/错误文案及旧回调隔离，按下方步骤验证。

## 人物广告尺寸一致性复验

2026-10-06 用户反馈“验收正常，部署生产吧”；以此记录本轮 staging 验收确认，未收到分设备版本、录像或逐项记录。staging/production 双端复用保持开启，诊断关闭；当前生产客户端配置及人工待办见[全部验收生产交接](./releases/全部真机验收功能-生产客户端交接-2026-10-06.md)。本手册下列步骤保留供后续复验。

1. 仅独立 staging develop，至少一台 iOS 和一台 Android，分别验证真实/示例家谱。权益在进页、重新进入、刷新和切谱时确认，顶部与人物广告共享同一家谱的并发查询；同页反复打开不重复查权益，其他家人开通会员允许在下次进入家谱页时确认。当前家谱有效期内或永久会员的全部有效角色（管理员、成员、只读成员）均不显示整个模块；未知权益、查询失败、无有效家谱、无广告位、组件不支持及注销冷静期也不显示。会员购买返回重新确认；已知到期先重新查询，确认免费前保持隐藏。会员入口只在已确认免费模块出现后可用，加载期间也可进入；跳转前销毁实例并关闭弹框，旧家谱模块不能购买。
2. 免费权益确认后预取广告数据，并用不含广告的同样式普通布局槽提前测量像素宽度；首次打开前不创建原生广告。已确认免费时显示广告模块，广告未就绪、无填充、加载失败或 10 秒超时均在广告内容区水平垂直居中显示“广告位，收益用于运营开支”，成功加载后移除文案。模块保留左侧关闭 icon、右侧“开会员，全家人免广告”、至少 200rpx 广告区、固定竖屏 80vh/横屏 100vh 和整体自然高度滚动。wx.preloadAd 仍按应用广告位去重，仅 requested/unsupported/failed，不代表真实广告就绪；接口不存在或抛错仍可见后加载。打开使用已测宽度，零宽下一帧重试一次，仍失败保留文案，下次打开重测；窗口变化可提前测量普通槽，宽度变化重建，尺寸变更不增加会员查询。不得使用零宽创建、裁切或拉伸广告。核对测量普通布局槽中没有广告，打开前已有像素宽度；横屏侧栏的最大宽度、安全区、边框和内边距同实际弹框一致。广告槽与组件边界宽度差目标不超过 1px。
3. 实例存在、加载就绪与弹框可见分别管理；同宽组件在当前可见弹框内复用。普通关闭及模块关闭仅隐藏本次展示，通过平台验收后保留原生实例和就绪状态，下次打开直接复用；模块关闭只影响本次弹框。隐藏同时作用于弹框、模块及广告组件；关闭后视频、声音和点击区域必须消失。2026-10-06 用户确认 staging 复用验收正常并明确授权部署生产，staging/production 的 ios/android 复用均为 true，验收诊断均已关闭。验收依据为用户确认，未提供分设备版本、录像或逐项记录；不补写独立验证证据。异常平台可将对应环境开关恢复 false，关闭时销毁实例，只保留数据预加载、权益与已测宽度；不得依靠运行时猜测视频泄露。宽度/广告位变化、切谱、离页及会员生效清理实例；失败和超时清理失败实例、保留文案，本次不循环重试，下次打开允许重试。有效的隐藏实例加载可更新就绪缓存，但不能恢复本次展示；旧实例事件与旧尺寸流程不得恢复已关闭模块。先将对应平台复用开关临时关闭以验证销毁兜底，再恢复本次待验收的 true 配置进行至少 20 次视频/图文素材的普通关闭、模块关闭及快速重开；包括后台返回、横竖屏、查看资料、排行、折叠、会员跳转、切谱、离页。任何泄露就恢复对应 false；通过后登记设备系统、微信版本、广告素材类型、实例版本和截图/录像证据，才能保留对应 true。
4. 验收诊断目前已关闭；需要补充证据时临时开启 memberAdDebugEnabled.staging，只记录阶段、弹框开关、mounted/loaded、像素宽度、预加载请求状态、实例版本及边界宽高，不记录人物/用户信息。measure/measure-retry 来自普通槽，可在弹框打开前或关闭后出现；created 只在首次可见展示时出现。通过复用的平台，关闭后 loaded 可更新隐藏实例，但不得恢复模块。结束后关闭诊断。
5. 无填充、错误和 10 秒超时应清理失败组件、保留居中文案；本次不循环重试，下次打开可重试。零宽及视图提交各阶段关闭不挂载广告。成功加载移除文案、保留自然素材比例和完整原生按钮；文案不覆盖广告。
6. 2026-10-05 的旧版视频泄露截图作为历史缺陷证据保留。用户已确认本次 staging 复用验收正常并授权生产交付，未附分设备记录；用户已确认全部真机验收完成；本轮 v1.6.5 人工上传后的 production 体验版冒烟仍待执行；失败的平台恢复销毁；不得以 requested、本地回归或模拟器认定缓存命中、真实打开速度及视频隐藏已通过。本轮 UI 连接超时，AI 未上传、提审或发布。

## 开屏与广告购买入口验收

1. 在开发版 `develop` 确认运行环境为独立 staging。使用当前免费家谱分别从普通启动、邀请链接、示例分享、扫码及订阅提醒入口冷启动，核对开屏后原目标、完整参数和人物视角不丢失；后台返回和页面切换不得再次开屏。
   客户端开屏启用时，普通启动首个页面为开屏，链接入口立即转入开屏；权益查询阶段只显示水平居中的 Logo 和“有谱家谱，传承家族记忆”；Logo 与文案整体上移，可用高度内上下留白约为 4:6，横屏及小屏文字完整，不出现“正在准备／正在进入”和提前的按钮区，也不先展示业务内容。Logo 必须与用户提供的统一 Logo 一致，来自 `config/brand.js` 和 `images/brand/logo.jpg`，不得显示分享插图，不增加强制停留；广告加载成功后才出现底部操作区；无填充、加载失败或关闭时不能闪出“直接进入”或会员按钮。退出先清理视图再跳转，重复点击及迟到加载不恢复操作区。
   在 `miniprogram/config/commerce.js` 将 `launchAdEnabled.staging` 临时设为 `false`，保留 ID，冷启动应直接进入首页且不显示品牌页、不调用开屏权益查询；邀请/分享应直接到原目标并保留参数。再启用并临时清空 staging ID，应同样直接进入。用完恢复 staging 当前配置（`true` 与既有 ID），production 不改。导航失败时只在品牌内容内显示独立的“重新进入”，不显示广告操作区；重试成功前应先完成视图清理。客户端开关与后台封面广告开关不能混用。
2. 以当前会员家谱的管理员、成员和访客冷启动，应不创建广告组件；切到其他免费家谱再冷启动应重新判断。无有效家谱的新用户继续直接进入示例。到期、退款或购买完成后返回均应刷新判定。
3. 微信后台原生模板广告选择全屏模板，核对广告标识、素材比例及原生关闭控件；会员入口与跳过操作不得覆盖广告内容。广告加载成功后可随时跳过，5 秒自动进入；关闭、无填充、加载错误及等待 3 秒均进入原目标。
   新版布局为顶部安全区、按可用窗口高度分配的广告区域、底部跳过与会员操作区；确认购买入口不挤到顶部，按钮区不覆盖原生广告。超高模板按测得比例尝试缩窄，短模板居中，不用 `height:0` 滚动容器，也不拉伸或裁切填空。缩窄外层宽度不能证明原生信息区位置正确，模板配置须另按下节复验。
4. 从开屏购买入口进入会员页，核对选中当前家谱；取消或完成购买再返回时直接进入原目标。离开页面后，计时器及迟到广告事件不得再触发导航。
5. 家庭、我的两个 Banner 位待人工提供 ID 后核对广告下方入口；真实/示例人物弹框已在 staging/production 配置原生模板 ID，入口位于广告上方，文案为“开会员，全家人免广告”。各入口均绑定当前家谱，购买返回后会员身份无广告；无 ID、无有效家谱、会员及未知权益不显示模块；免费人物广告未就绪或加载失败保留居中文案；模块关闭移除本次展示。
6. 开发者工具或真机未返回真实广告时，只记录流程结果，不将真实填充、全屏模板布局或平台审核记为通过。体验版 `trial` 路由 production，不能用于本次 staging 验收。
7. 如继续出现展示不全或下半屏空白，保留当前完整真机截图、该广告位的后台模板预览，以及真机调试控制台 `开屏广告尺寸（staging）` 日志。日志包括窗口大小、页面、顶部安全区、广告区域、模板外层、原生节点、底部操作区边界及适配后的宽度；节点不能读取时保留 `null`，不得据此推断广告完整。旋转窗口时按新的可用高度适配，倒计时不重启。确认后台发布模板的比例、素材区和信息区后再调整；[官方组件文档](https://developers.weixin.qq.com/miniprogram/dev/component/ad-custom.html)仅支持调整广告宽度，不提供高度属性。

### 原生模板展示配置与复验

2026-10-04 的两张真机截图已返回真实广告：横版素材在竖屏全屏画布内上下留黑，竖版素材占据大部分画布；两者的原生文案和“查看／立即下载”信息区都在素材中间，小程序跳过与会员按钮在底部。这证明需核对原生模板内部布局，不能继续把信息区误当作小程序按钮调整。

平台专属配置由人工完成，依据见[开发规范](./开发规范.md#6-ai-与人工分工)。当前 staging/production 均配置已验收的 `adunit-84d9de0b742d77e1`，production 随 v1.6.5 人工上传生效。操作与证据要求：

1. 微信公众平台 → 流量主 → 广告管理，找到该 ID，进入模板编辑器；保存当前画布类型、素材区、信息区和模板托管状态的预览。截图本身不能确定后台具体配置。
2. 在编辑器实际提供的布局中，选择原生信息区位于素材下方的样式，保留广告标识、文案、图标及原生按钮。分别检查图片与视频比例和预览，不以小程序自绘下载按钮替代。官方手册给出全屏及卡片等画布，卡片示例包含“上图下文拼接”；该示例不证明当前全屏广告位支持同名布局。如果全屏编辑器无法满足下方信息区，记录限制，再明确是否更换模板类型及广告位；不得未经确认改用插屏或封面广告。
3. 核对模板托管：官方说明托管会择优展示相同画布类型下的其他样式。若编辑器提供关闭选项，可由人工关闭后固定所选样式复验；保持开启时，要验证可能返回的样式都符合下方信息区要求。不要把托管推测为本次问题的已确认原因。
4. 人工完成平台模板配置后，在独立 staging 的 `develop` 开发版冷启动。横版和竖版素材都检查完整边界，信息区在素材下方，应用跳过/会员区在整个原生广告之后；广告标识、原生按钮和胶囊不遮挡。横版素材等比例留白允许保留，不能把“只投放竖版”作为客户端验收承诺。
5. 分别记录素材类型、后台模板预览、托管状态、完整真机截图和版本。只返回一种素材时，另一种明确记为未完成；平台配置未调整或原生信息区仍在中间时，展示验收不能通过。

依据：[微信原生模板组件文档](https://developers.weixin.qq.com/miniprogram/dev/component/ad-custom.html)、[腾讯广告官方接入手册](https://training.tencentads.com/uploads/202406/EPLBpxYt_5dDA71.pdf)第 13、31、39—44 页（2026-10-04 核对）。官方手册说明编辑器和托管能力；信息区必须位于素材下方是本产品本轮要求，不将素材叠加样式一概称为平台违规。
