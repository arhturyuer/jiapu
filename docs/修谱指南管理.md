## 内容与编辑

运营后台“修谱指南”对有效 operator 和 super_admin 开放。文章列表可搜索标题、按状态筛选，按草稿排序值升序排列。新增时填写唯一 slug（小写字母、数字和连字符，最多80字符）；创建后固定，回收站中的 slug 仍保留，分享路径继续为 pages/guide/index?slug=<slug>。

标题最多100字符、摘要500字符，排序为0～999999整数，最多8篇关联阅读。正文使用 Tiptap 3 富文本，支持二／三级标题、段落、加粗、斜体、下划线、项目／编号列表、引用、图片及撤销重做；问答可在正文中自由编辑。正文以结构化 JSON 存储，最大200KB、3000节点、12层嵌套、30张不同图片；服务端白名单校验，不接受代码、脚本、外部链接、iframe、外链图片或未知属性。

保存草稿不改变公开内容。标题、摘要、顺序、正文、关联阅读在预览确认后随发布一并生效。列表页顶部标题与说明有独立草稿及发布操作，初始内容沿用原文。未保存离开需确认；页面刷新／关闭提示未保存修改。修订号冲突时拒绝覆盖，须重新读取后合并修改。

下架立即停止后续公开读取，保留内容可再次发布。删除移入回收站并停止公开读取，恢复后为未发布草稿，需重新发布；没有永久删除按钮。已打开页面和已保存的图片副本不受即时撤回控制。关联阅读只展示仍已发布的目标。

## API 与安全边界

运营动作经 youpuOpsApi，沿用 action、success/data、success/code/message/requestId：

- guides.list：keyword、status、pageSize、cursor；返回 items、hasMore、nextCursor。稳定排序为排序值、ID，单页最多100篇，总量超过2000篇明确拒绝。
- guides.detail：guideId；返回运营可读的草稿、发布快照、revision、指南图片临时地址。
- guides.create：slug、draft；返回 guideId、revision。draft 包含 title、summary、sortOrder、related、body。
- guides.updateDraft：guideId、revision、draft；guides.publish/unpublish/delete/restore：guideId、revision。所有写入沿用 requestId 事务幂等及运营审计；重试原请求保留同一 requestId。
- guides.settings.get/updateDraft/publish：列表配置读取、保存与发布；写操作需 revision，保存另需 draft（title、summary）。
- guides.image.upload：guideId、imageData（data URL）、requestId；返回 assetId、url。需先创建文章，仅允许PNG／JPEG／WebP、最大1MB，并核对文件头与声明格式。

指南图片由运营云函数上传到独立 ops/guides 路径、登记 guide_assets；正文只保存素材ID，不保存临时地址。素材属于具体指南，不能跨文章引用，也不能使用私人家谱素材。上传按文章和内容指纹去重。当前版本保留素材，不自动清理草稿、发布或回收站可能引用的图片。

公开接口由 youpuUserApi 提供 public.guides.list/get（使用 type），无需业务账号，有限流，不创建 users 或原业务活跃记录。list 返回已发布标题、摘要、顺序、slug和列表文案；get 输入 slug，返回 guide（slug、title、summary、nodes）及有效关联摘要。仅为当前发布快照引用的有效指南图片签名；图片签名失败仍返回可读正文与占位提示。草稿、运营身份、私人媒体和原始数据库记录不公开。集合继续 ADMINONLY，客户端不直连数据库。

小程序每次进入列表或详情重新请求，原生 rich-text 使用白名单节点与相对字号，图片自适应宽度。加载、空内容、不可用和可重试错误独立展示；离页后忽略迟到响应。不使用内置旧文章或持久缓存回退，避免下架后重新出现。图片临时地址失效可重新读取页面。新增已发布 slug 可进入原增长统计，已下架／删除内容不再接受对应详情事件；其余归因口径不变。
