# iPad 与电脑微信端适配

本说明为现行规范。开发入口见[文档索引](./文档索引.md)，验收见[发布验收清单](./发布验收清单.md)。2026-10-10 已完成客户端实现与本地检查，设备验收结果以[本次交接](./releases/大屏适配-交接-2026-10-10.md)为准；不得把离线编译当作真机通过。

## 布局与导航

覆盖当前 29 个小程序页面，运行范围为 iPad、Windows 微信及 Mac 微信；没有独立浏览器网站。`app.json` 开启 `resizable`。设备类型与布局分开：按窗口逻辑宽度划分 compact（小于 600px）、medium（600～1023px）、expanded（至少 1024px）。电脑窄窗口、iPad 窄分屏使用单列布局；分屏是否可用由微信客户端决定。

手机原布局保留。大屏界面按 375px 设计基准固定控件尺寸，页面正文基准为 16px；主要按钮及图谱控制按钮至少 44px。表单、设置、协议、导出等内容最大宽度 720px，家庭、我的、成员及示例列表最大宽度 1120px；家庭和我的页在 expanded 档分组为两列，表单按现有区块分栏，成员列表在 medium 及以上使用按行排列的两列卡片。

公共弹窗居中、最大宽度 560px，超高内容可滚动；大屏家谱人物弹层在右侧，宽 360px，保留遮罩与既有动作。成员保存栏与会员购买底栏同正文限宽，保留安全区和正文底部留白。日期组件单独适配，不依赖跨组件样式穿透；大屏触摸选择器的选中条与选项均为 44px，低高度窗口缩短滚轮区域并保留面板滚动。

iPad 和电脑跟随窗口变化，默认保留家谱工具栏和原生导航，仅手动清屏时隐藏；方向切换按钮只在手机显示。手机横屏沉浸规则保持。家谱完整利用剩余区域，顶部工具栏按内容实测高度。窗口至少 600px 时，查看方式／导出／邀请家人保持一行，放大字号及长辈模式同样适用；查看方式占剩余宽度，长名称单行省略，导出和邀请保留完整文字和点击区域。窗口事件与 page-meta 事件合并，每 60ms 最多应用一次最新尺寸；不重算关系布局，保留当前人物与视觉中心。普通 view 探针实测 rpx 换算，测量缺失时使用窗口宽度估算，图谱节点及关系线保持同一坐标体系。

## 平台能力与兼容

- 电脑左键拖动画布、点击人物；按钮执行放大、缩小与全谱查看。支持键盘 API 的电脑微信可用 `+` / `-` / `0`；弹层、输入焦点及后台期间不操作图谱，离页仅移除本页监听。
- 滚轮缩放未验证，不绑定不存在的普通小程序事件，不借用小游戏接口。本版使用拖动、按钮、可用的键盘 API；没有启用滚轮增强。
- 电脑日期使用可点击的年月日选择，公历、农历、闰月、部分精度及取消语义复用现有逻辑。头像选择返回同一上传输入结构，电脑仅提供图片选择，不请求拍摄；服务端审核与权限不变。
- 电脑图片及 PDF 提供“保存到电脑”，使用 `wx.saveFileToDisk`，缺失或拒绝时给出可读提示，取消不报错。手机保留图片相册保存，文件生成、权益和导出格式不变。
- 电脑虚拟支付尚未设备验证，本版明确提示使用同一微信账号在手机打开当前家谱开通，不创建电脑端购买订单；staging mock 支付测试保留。权益查询、付款记录和兑换功能继续使用原有服务端协议。
- 广告继续按真实容器测宽、尺寸变化后重测；不支持、加载失败、原生关闭及超时释放占位，下次主动打开允许按原重试策略恢复。手机添加到我的小程序引导须有真实有效胶囊位置；电脑、iPad 不显示或消耗自动提醒次数。

## 维护与验收

页面原始手机 WXSS 是控件尺寸来源。改动含 rpx 的界面样式后运行 `node scripts/generate-large-screen-styles.mjs`，更新各文件标记内的大屏 px 覆盖；图谱内部几何、徽标及关键帧不转换。手写布局放在 `large-screen:layout` 标记后，或公共 `styles/large-screen.wxss` 中。该脚本不在应用运行时执行，不引入依赖。

统一运行 `bash scripts/check.sh`；包体保守预算仍低于 1,500,000 字节。测试使用虚构配置与依赖替身，不连接云端。可使用微信开发者工具自带 WXML/WXS 和 WXSS 编译器进行离线语法检查，但它不能确认渲染、设备事件、支付或平台回调。

设备验收必须使用独立 staging 的 develop 开发版：记录设备、系统、微信版本、逻辑窗口宽高、入口和结果。体验版 trial 与正式版 release 路由 production，不能作为未获生产授权的大屏验收入口。适配无云函数、索引、安全规则、数据库或后台变更。用户后续要求服务端部署，2026-10-10 已同步四个现有 staging 函数并完成配置、50 项源码回读与 4 项安全拒绝冒烟；人工开发版入口和设备验收待完成，详见[交接追加记录](./releases/大屏适配-交接-2026-10-10.md#追加staging-服务端部署与开发版验收准备)。

2026-10-11 用户确认 staging 验收完成并授权生产，v1.6.11 已准备；生产四活动函数的 50 项源码及运行配置已核验一致，本次无需重复部署服务端。完整生产预检的微信 preview 受自动审批限制尚未通过，见[生产交接](./releases/大屏适配-生产交接-2026-10-11.md)。用户验收确认不补充缺失的分设备能力证据；滚轮和电脑真实支付仍按上文边界处理。

## 与字号和长辈模式配合（2026-10-11）

全局阅读变量保持逻辑 px 字号，现有生成器仍生成大屏尺寸基线，不将语义字号重新固定为 15/16px。图谱内部尺寸按统一阅读倍率，100rpx 几何探针保持不变。唯一入口在我的帮助与反馈；普通模式保留原大屏布局和交互，仅放大字号时做必要防裁切适配，长辈专属单列和大按钮按开关生效。新增设置页及两种模式在 600/1024px 边界、iPad 和电脑微信分别验收，不能沿用此前大屏验收证明本轮大字效果。详见[适老化说明](./适老化说明.md)及[实施交接](./releases/长辈模式入口与启用边界-交接-2026-10-11.md)。

2026-10-20 人物操作弹框广告模块：关闭按钮固定靠左，普通／长辈点击区域至少 44／60px；会员引导靠右占用其余宽度，去除挤占空间的默认按钮宽度和左右内边距。空间足够时完整单行，极大字号或窄面板自然换行，不缩小字号或裁切文字；操作行垂直居中，位于广告内容上方，不覆盖原生广告。实际设备边界见[本地交接](./releases/人物弹框广告会员引导-本地交接-2026-10-20.md)。
