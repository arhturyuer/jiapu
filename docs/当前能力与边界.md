# 当前能力与边界

本说明依据仓库代码及本地测试，核验日期见[文档索引](./文档索引.md)。它不证明线上已部署、平台配置已完成或小程序已经发布。[V1.0 产品方案](./有谱产品方案.md)仅作为历史设计资料。

## 用户端

- 三个 Tab：家谱、家庭、我的；创建家谱、邀请加入、官方示例、全谱及任意人物视角、搜索、分支折叠、横竖屏浏览。真实与示例家谱均可从画布控制组打开显示设置，也均可从“图片”直接生成当前已展开布局的高清图；两者共用同一渲染、高清限制、预览、发送和保存链路。真实家谱图片码及图片消息下方的小程序入口通过长期仅查看邀请回到实时家谱；示例图片码及消息入口回到当前已发布示例的对应全谱或人物视角。旧图片消息若仍指向临时预览页，失效页的“返回家谱”在冷启动时进入家谱 Tab。真实家谱显示偏好按用户与家谱保存，示例按设备和示例本地保存；示例发布新版本后采用该版本默认展示，用户之后的本地调整仅在当前发布版本生效。智能收起开启时把较大家谱的首屏控制在约 36 人；用户可关闭后完整展示所有成员，也可继续手动折叠分支。无已保存偏好的真实家谱新用户默认横排姓名、关闭子女排行和性别标识、开启性别配色与智能收起；旧示例缺少发布设置时使用原有默认值。真实家谱已有偏好缺少智能收起字段时仍按开启处理。
- 用户与示例家谱图共用多配偶家庭布线：不同配偶组合和单亲子女分轨连接，通道不足时增加代际留白。每对配偶从双方卡片侧边以同一高度绘制一条水平线；远端关系的中段画在其他人物卡片下层，同侧多条夫妻线错开高度。每组子女从远端配偶旁的卡片空隙向下接出。不可避免的交叉以断横线、连续竖线标明；高清图片使用同一布局与标识。
- 官方示例列表仅页面纵向滚动、顶部分类标签横向滚动；切换分类后仍可选其他分类。卡片简介默认展示三行，超出时可在卡片内展开和收起，点击卡片其他区域进入家谱。示例简介最多 1000 字，保留分段与空格；既有已截断文字无法自动恢复。
- 新建成员要求姓名和明确性别；存量未知性别继续显示“未填”。可补充头像、生日、籍贯及简介；支持关联已有成员、子女排行、人物卡与多重称谓路径。
- 同一家长的子女按可判定的出生先后、已确认的手动顺序排列；两者都不能区分时，长子默认在长女左侧，性别未填者排在已知性别之后，再用有效出生日期是否已填写、姓名和 ID 保持稳定顺序。手动确认长女在前时保留该顺序。真实与示例家谱图及排行面板共用此规则；不同配偶组合仍按家庭分组。
- 真实与只读示例的人物操作弹框保留“查看资料”入口，只有已录入有效子女时显示折叠操作，并直接列出可添加的亲属方向。已有明确性别父亲或母亲时，弹框隐藏对应方向；未知性别父母不占用方向。此限制只作用于弹框入口，不改变添加页面和服务端关系规则。示例方向点击后引导创建自己的家谱。弹框横幅广告仅在配置有效广告位、未享有会员去广告权益且广告加载成功时显示；无广告不预留空白。
- 家谱角色为 admin/member/viewer；管理员直接维护，member 经申请审核，viewer 只读。普通微信邀请仍仅由管理员生成并默认 30 天/50 次；图片分享码可由所有已加入角色生成，固定只读、不限时间和次数，并由管理员统一撤销。支持角色管理、管理员转让、退出和归档恢复。
- 隐私中心包含个人资料导出、注销冷静期及取消；家庭历史、家庭备份、会员与订单页面、分享和反馈群入口已有实现。具体会员权益以服务端 `commerce.js` 为准。
- 用户端云调用通过统一错误语言层展示网络、超时、权限、内容冲突、限流、内容安全、支付和文件处理提示；原始微信错误只用于取消判断和受控日志。完整请求编号可作为“问题编号”供客服排查，默认不在页面显示。

## 服务端与运营端

- 用户业务入口 `youpuUserApi`、运营入口 `youpuOpsApi`、用户触发后台任务/每日保留任务/审核回调 `youpuJobs`；个人导出与家庭备份按请求异步派发，支付查单由平台通知或用户显式动作触发，不再周期扫描；支付通知代码单独部署，staging 为 `youpuPaymentNotify`，production 目标为 `youpuPaymentNotifyV2`。
- 后台具备概览、用户/家谱查询、举报处理、内容复核、注销、审计、运营账号、官方示例、反馈群和商业化管理。
- 运营人员需登录且属于白名单；operator 与 super_admin 分权。默认列表脱敏，受控查看记录具体运营账号；当前实现不要求通用工单关联或所有操作填写原因。举报处理结论、拒绝复核原因及标记违规原因仍必填。
- 运营后台可管理官方示例，但不能编辑真实家庭的人物关系。图片具有审核/复核两种准入策略，详见[媒体约定](./有谱开发部署说明.md#6-内容安全与媒体)。
- 示例简介保存、发布与用户端返回沿用 `description` 字段；超过 1000 字（含空格和换行）明确拒绝，不静默截断。普通家谱简介仍遵循原有 200 字限制。
- 官方示例每份最多 200 人、400 条关系，支持 Excel/CSV 导入预览；姓名缺失或重复、关系人物无法匹配、无效或重复关系、自关联、祖先循环及数量超限会一次列出到表格行和具体人物。有错数据可载入本地草稿逐行高亮修正，未全部修正前不能保存或发布。保存请求中的关系端点可使用人物姓名，由服务端在校验前唯一匹配；已保存草稿的内部 ID 格式继续兼容。
- 运营后台的示例编辑器按家谱资料、人物表、关系表、预览图和默认展示切换；预览图按草稿展示设置渲染，点人物或关系线可跳到对应表格。每份示例可单独设置五项默认展示偏好，保存到草稿后由超级管理员发布；所有设备在收到新发布版本后采用该版本默认值，随后用户的本地调整在这一版本内保持。旧示例没有发布设置时使用原有默认值。
- 示例草稿的运营后台关系图复用小程序布线坐标和交叉标识；点击可见关系线可定位表格行，共用线段涉及多条关系时先选择对应关系。

## 已知边界与未确认事项

- 图谱人数上限、集合 schema、运行规格以初始化代码及部署清单为依据；本地测试验证部分算法和契约，不能替代真机表现、云权限和平台回调验收。
- 旧方案中的生日订阅提醒、通用工单分配、成员合并和任意历史版本回滚没有完整交付证据，不作为当前能力承诺；是否继续建设由后续需求决定。
- 地域/家庭自定义称谓尚未提供。图谱关系搜索有计算预算，截断时提示，不承诺穷举全部路径。
- `familyFunctions` 是否仍被调用、旧支付通知函数是否可下线、生产配置和告警是否实际生效，需要另获授权后云端核验。仓库存在旧代码不代表线上仍使用，也不构成可直接删除的依据。
- 平台套餐、资质、支付商品、消息绑定、广告开通及审核发布状态均为外部事实；每次涉及时重新确认，不能沿用历史“已完成”记录。
