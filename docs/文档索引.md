# 文档索引与处理清单

本表是仓库 Markdown 的统一登记入口。核验日期表示本地内容核对，不表示云端或平台已验收。新增、移动、归档或删除文档时同步更新本表；执行 `node scripts/check-docs.mjs` 检查结构和本地链接。

状态含义：**现行规范**用于当前工作；**规划草案**需要进一步决策；**历史记录**只证明记录时点；**已废弃**不得用于操作。历史和规划文档必须提供现行入口。文档与实现冲突的处理见[开发规范](./开发规范.md#5-文档与代码同步维护)。
