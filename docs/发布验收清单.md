# 有谱版本发布验收清单

> 文档状态：现行规范。AI 完成服务端交付，人工上传、提交审核和发布小程序。使用[交接模板](./releases/TEMPLATE.md)保存实际结果；未执行项不得勾选。

## 发布硬门槛

- [ ] 本版本功能已部署至独立 staging 环境。
- [ ] staging 测试验证已通过：自动化测试、构建和与本版本改动匹配的功能验收均完成。
- [ ] 发布负责人已在当前请求中明确确认“发布到 production”。
- [ ] production 部署命令已通过仓库现有目标与确认护栏。

未满足以上任一项时，只允许发布到 staging。下列项目用于按变更风险选择的完整验收与长期运维记录，不阻塞不涉及相关风险的常规功能版本。

## 自动化与构建

- [ ] `bash scripts/check.sh` 通过：自有 JS/MJS 语法、文档、全量测试和类型检查。
- [ ] 管理端 `pnpm run typecheck` 与生产构建通过。
- [ ] 微信 CLI 预览通过，基础库与 `project.config.json` 一致，`urlCheck: true`；预览为 develop/staging，不能代替生产体验版验收。
- [ ] 记录发布分支、完整提交 SHA、未提交改动；如创建标签，使用实际版本号。文档已同步或说明无需更新的理由。

## 用户端

- [ ] 新用户首屏直接出现“创建家谱”和“接受邀请”，没有永久加载。
- [ ] 单次云调用具有 8 秒超时，网络失败最多自动重试一次；最终失败后结束加载，显示错误说明和重试入口；三个 Tab 均不出现永久空白。
- [ ] 管理员可直接维护；member 只能提交申请；viewer 只读。
- [ ] 默认全谱可用；任意人物视角、返回全谱、搜索和折叠分支可用。
- [ ] 真实与示例家谱的“智能收起”默认开启；关闭后全谱和人物视角均展示所有成员，仍可手动折叠，重新开启后恢复约 36 人首屏策略且当前视角人物不被隐藏。
- [ ] 500 人/对应关系首次有效渲染 ≤ 2.5 秒，拖动、缩放和切视角无明显卡顿。
- [ ] 邀请默认 30 天/50 次，并可撤销；20 个并发接受不超过次数上限且不重复入组。
- [ ] 家谱图片入口对 admin/member/viewer 均可见；点击后直接生成当前已展开布局，预览页只有发送和保存两个操作，原顶部微信邀请流程不变。
- [ ] 官方示例家谱显示同样的“图片”入口，共用真实家谱的标题、码区、布局、清晰度限制和预览交互；扫示例码返回对应已发布示例及当前视角，不创建家谱邀请。
- [ ] 图片码固定授予 viewer、长期不限次且可由管理员撤销；普通链接和扫码 `scene` 均进入正确全谱/人物视角，撤销后不能再使用。
- [ ] 真机把真实家谱与示例家谱图片发送给另一微信账号；从图片下方“打开小程序”进入真实家谱邀请或示例全谱/人物视角，不出现本地图片预览失效页。已发送的旧图片若仍打开失效页，“返回家谱”可进入家谱 Tab。
- [ ] 36 人和约 80 人展开布局的头像、姓名、关系与小程序码清晰；超过可读单图上限时提示收起分支，不生成模糊图片或上传完整海报。
- [ ] 管理员转让、退出、归档/恢复正确；最后一名管理员在 active 家谱不能退出。
- [ ] 缺少页面参数、无权限、弱网、服务错误都有安全状态和重试入口。
- [ ] 普通页面不展示动作码、英文状态、错误码、微信平台原文或内部文件结构；未知错误使用友好兜底。
- [ ] 变更历史、家庭备份、隐私与账户、家庭会员在 115% 系统字号和窄屏下不截断关键信息，主要点击区域不小于 88rpx。
- [ ] 支付中、确认中、成功和失败均使用统一状态卡，原始订单核对信息不进入页面。

## 数据与安全

- [ ] 唯一索引全部处于可用状态。
- [ ] 客户端数据库读写全部拒绝，未登录云函数调用全部拒绝。
- [ ] 自关联、重复、跨家谱、父母子女环均被拒绝。
- [ ] 重复写请求返回第一次结果；事务失败不留下半成品。
- [ ] 所有列表均可继续游标分页；超过 500 人明确报错而非静默截断。
- [ ] 图片只能进入本人私有暂存目录；PRIVATE 基线下创建者访问本人对象的限制已说明；业务短链需对应权限且仅返回 approved + active 资源。
- [ ] 存储生命周期未将整个 `staging/` 对象前缀设为 24 小时删除；批准图片仍存于该路径，旧指令不可沿用。

## 隐私与内容安全

- [ ] 隐私政策主体为公众平台登记全称，服务协议、客服、权限用途可访问。
- [ ] 首次隐私授权、拒绝相册/相机、撤回权限不影响只读浏览。
- [ ] 微信公众平台《用户隐私保护指引》已增加“使用你的相册（仅写入）”，用途为用户主动保存家谱高清分享图片；真机隐私授权清单可见该项。
- [ ] 保存家谱图片时，`scope.writePhotosAlbum` 未明确授权（包括 `getSetting=false`）会先实际调用 `authorize`，而不是直接打开无对应项目的设置页；实际拒绝后才展示小程序设置入口。仅在 iOS 返回 `albumAuthorized=denied` 时引导微信系统照片权限；权限已开启、Android 未返回该字段或普通保存失败时不得误报系统权限。
- [ ] 文本通过/疑似/违规结果正确；图片默认审核与复核模式分别验收 pending/review/approved/rejected、机审记录和人工违规隐藏。
- [ ] 人物、头像、家谱描述和邀请均可举报，用户可查看处理结果。
- [ ] 信息导出由后台任务生成私有个人资料文件（内部格式保持不变），仅申请人可领取一次且 24 小时后清理；注销 7 天冷静期可撤销，到期去除必要记录与用户身份的关联符合预期。

## 运营后台

- [ ] 未登录、非白名单均不可进入。
- [ ] operator 与 super_admin 权限矩阵正确。
- [ ] 用户/家谱默认脱敏；受控查看通过白名单鉴权并记录具体运营账号及审计，不要求通用工单关联。
- [ ] 举报处理结论、拒绝复核原因、违规原因必填；冻结、注销重试和运营账号操作按现有确认流程、角色权限执行并审计。
- [ ] 运营端不存在编辑家庭人物关系的入口。
- [ ] 示例家谱导入可一次列出全部人物/关系错误、数据行及 Excel 行号；重复项和祖先循环显示全部涉及行与具体姓名路径。
- [ ] 有错导入可载入本地草稿并逐行高亮；缺失或重复姓名不会被静默绑定，错误未清零时不能保存或发布，修正后可正常保存。
- [ ] 50 人、79 条有效姓名关系导入后可保存并回读相同人数与关系数，不出现每条关系两端均“未匹配”的误报；旧 ID 格式请求仍能保存。
