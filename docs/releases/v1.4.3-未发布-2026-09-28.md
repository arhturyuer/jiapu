# v1.4.3 成员操作弹框优化交接

> 文档状态：历史记录；记录时点：2026-09-28；不作为当前操作指引。当前发布规则见[正式发布运行手册](../正式发布运行手册.md)。

## 版本与变更

- 版本：`1.4.3`；更新摘要：`优化家谱成员操作弹框，直接选择亲属方向并按关系显示操作。`，与 `miniprogram/config/release-notes.js` 首项一致。
- Git 分支和工作基线：`main`，`d77196fb7a09f97c205535449d30ce299c973211`；本次改动尚未提交。
- 真实与示例人物弹框只保留“查看资料”入口，仅有有效子女时显示折叠后代；六类亲属方向直接展示，已录入明确性别父亲或母亲时隐藏对应方向。示例方向保持只读创建引导。
- 根据开发版截图补充布局修正：单条关系卡片改为视角称谓、人物路径两行并按内容定高；多条关系仍可在卡片内滚动，操作区末尾保留滚动空间，避免亲属方向末行被裁切。
- 针对微信代码质量扫描的主包超限，将 76,186 条静态称谓词表的条目和字段分隔符改为单字符编码；称谓内容与运行时查询规则未变。同步更新生成脚本和词表说明。
- 弹框底部新增独立横幅广告位配置；无广告位 ID、会员去广告或加载错误时不渲染广告。当前 staging 和 production 配置均为空，不会展示广告。
- 只改客户端、测试与现行文档；服务端协议、索引、安全规则和数据结构均未更改，不需要迁移。父母数量限制仅在人物弹框入口生效。
- 已同步[当前能力与边界](../当前能力与边界.md)、[设计风格规范](../有谱设计风格规范.md)、[发布验收清单](../发布验收清单.md)、[家庭会员 staging 验收手册](../家庭会员staging验收手册.md)和[文档索引](../文档索引.md)，核验日期为 2026-09-28。
