# 版本交接模板

复制为对应版本记录后登记到[文档索引](../文档索引.md)。新记录属于历史记录，顶部标注记录时点和“不作为当前操作指引”，链接[正式发布运行手册](../正式发布运行手册.md)。仅维护服务端状态，未执行项目写“未执行”，不得默认勾选通过。客户端发布生命周期不在记录范围内。

## 版本与变更

- 版本、更新摘要及Git分支、完整提交SHA、未提交改动：
- 实际改动、服务端组件及影响；必要的客户端改动说明与接口兼容证据：
- 文档更新和核验日期，或无需更新理由：

## 环境与授权

- 目标staging/production、实际环境、部署时间与执行者：
- production当前请求的明确授权依据；staging实际ID仅留受控本机记录：
- 服务端平台配置项及完成证据，不输出密钥：

## 验证和兼容

- 本地检查／构建／生产预检的命令、时间、结果及失败或跳过项：
- staging服务端验收入口、虚构资料标识及结果：
- 现有客户端协议兼容性、接口、索引、安全规则、schema及迁移：
- 实际部署组件、源码与配置回读、服务端验证入口及结果：
- 回滚代码与受控配置、数据兼容及待确认订单处置：
- 持久受控证据位置及脱敏摘要：

## 服务端交接状态

| 项目 | 状态（未执行/进行中/通过/失败/不适用） | 操作者、时间与证据 |
|---|---|---|
| 服务端检查与构建 | 未执行 | |
| staging服务端部署与验证 | 未执行 | |
| production服务端部署与回读 | 未执行 | |
| 服务端回滚与运维待办 | 未执行 | |

当前服务端状态：待部署／部署中／待验证／验证通过／部署失败／无需部署（按证据填写）。

## 服务端剩余事项

- 云函数、后台、索引、规则、运行配置、平台回调及运维待办：
- 服务端监控结果、负责人、复验条件和阻塞：

小程序上传、体验版设置、提审与发布仍由人工负责，不纳入交接状态、待办或后续追问；具体操作说明见正式发布运行手册。
