## 公开阅读与收录

面向想为自己家修谱的人。无指定页面且无本机家谱记录时从启动页直接进入默认示例 pages/example/index?entry=default；有记录时进入原家谱页。本机记录仅决定路由，不授予权限。邀请、示例、指南直达目标不改变。介绍、关于、法律说明、指南与官方虚构示例不经过启动广告，也不以业务账号建档成功为阅读前提；创建、加入、导出等业务请求通过原身份和权限校验。公开页面切回前台也不能触发自动建档。

`sitemap` 显式允许介绍、关于、指南列表/详情、示例列表/图谱/文字说明/人物资料，其他页面默认禁止。公开链接使用原生 navigator；参数采用准确键集合，排除 source、select、personId 等追踪或模式变体。sitemap 只声明收录许可，不提交页面，也不能保证收录或排名；禁止索引不能代替业务鉴权。

公开入口清单：

示例文字说明中的全部人物列表、人物资料中的亲属姓名使用原生 navigator 进入相同人物资料页，必须传入 `slug` 和 `id`。WXML 的 URL 属性直接使用 `&id=` 连接参数；写成 `&amp;id=` 会被原生编译器保留为 `amp;id` 参数，导致人物 ID 缺失。

公开 API `public.examples.list/get/resolvePoster` 沿用 success/data 与 success/code/message，只访问已发布的官方示例快照，排除草稿和私人媒体。旧 examples 接口保留身份校验。公开调用不自动创建 users 或写入原业务活跃统计。public.share.record仅接受公开发现卡/已发布示例的prepared、sent、opened事件，沿用原分享计数和请求幂等，不接受邀请标识；公开分享不因计数而建档，私密邀请仍走旧接口。允许无业务账号读取不意味着开放客户端数据库读权限；集合继续 ADMINONLY/deny-all。公共接口仍有限流。

## 默认示例首屏

默认入口直接取后台排序第一的已发布示例，沿用已发布内容、展示设置和既有分支展开能力，不新增推荐字段、人物限制或专用示例。所有示例入口共用同一布局：保留原导航标题，其下为“浏览示例家谱”、横向标签和与真实家谱一致的查看方式、导出、邀请家人操作区。底部常驻“认识有谱／修谱指南”原生链接与创建主按钮、切换家谱示例次按钮；点击介绍或指南后，左上角返回来源页，无上一页时显示统一线条首页图标。我的页帮助与反馈首项也可进入修谱指南；创建进入原建谱流程，不复制示例。移除图谱页的示例说明快捷链接，文字说明页及人物资料仍保留虚构、只读说明和公开入口。

顶部查看方式、导出、邀请家人三项统一高度，常规字号均为44px；大字号／长辈模式按同一规则增加高度。查看方式提供全谱和人物搜索，取消、重复选择保留取景；全图仅适应画布，不改查看方式。导出菜单提供家谱图片、家谱树大图 PDF、家谱书 PDF，调用原示例导出与校验。邀请家人直接原生转发当前示例及人物视角，不创建真实邀请。右下普通／长辈统一放大、缩小、全图、横竖屏、设置、清屏；大屏省略方向按钮。普通人物首次点击选中、高亮，再次点击或操作按钮打开卡片；长辈仍单次打开。切换示例和离页关闭菜单、取消搜索并隔离迟到响应。

底栏固定在全高页面底部，画布使用剩余 flex 空间，实测头部、底栏和画布用于取景兜底及工具排列，不叠加第二份底栏占位。手机横屏保留紧凑底栏，清屏隐藏头部、底栏及工具，退出恢复。底部创建和切换固定等宽两列，覆盖微信默认按钮宽度；大字号仅在按钮内部换行，不将两个按钮堆叠；极大字号时头部、底栏可在各自限高区域滚动，保留可操作画布，弹层覆盖底栏。实现及本地验证见[布局交接](./releases/示例家谱底栏与统一交互-本地交接-2026-10-19.md)。

默认入口与明确slug/scene入口的可见页面结构一致，入口标识仅决定广告策略和增长统计：默认模式不请求、预留或展示人物广告，切换其他示例后仍保持此标识。明确直达的既有广告策略保持。仓库改动前的页面只作为结构参考。

创建在加载或失败时仍可用，进入原建谱流程，不复制示例；空列表、读取失败、下架显示明确错误，重试公开接口，了解有谱保持静态可读，不自动循环跳转。介绍页继续独立存在。默认模式参数不进 sitemap；规范示例 slug 地址保持可收录。

## 增长统计口径

`growth.record` 输入 event（view/example/create_click/landing/load_error）、公开 page、slug、App 启动/前台场景 scene，可选 entryType 只接受空值或 default_example（仅示例页）；不接受任意 URL 和私人内容。只有服务端微信身份用于生成脱敏 visitor ID，不接受客户端指定用户。没有身份返回 recorded=false，阅读仍可用。按访客、北京时间日、事件、公开内容去重；不创建业务用户。

默认入口 onLoad 先记 landing，不等列表或图谱加载，再串行上报成功 example 或 load_error；无可用示例也能记录曝光和创建点击。landing、load_error 及默认模式 create_click 固定空 slug，成功 example 仍校验已发布 slug。新增事件仅用于 default_example；旧请求省略 entryType，沿用原幂等键与校验。新入口类型加入事件去重键，不覆盖既有首次触达和归因时间。创建按钮最多等统计1秒，不以统计成功为业务前提。

首次触达来源在服务端由上报场景映射：1005、1006、1027、1042、1053、1183 为搜索，1007、1008、1044 为聊天分享，其余未知。1129（爬虫）、1030（自动测试）、1203（压测）不记用户级漏斗；独立 staging 测试身份单独标记，不进入正式报表。来源是客户端场景分类，不能作为访问权限或微信官方流量报表。未使用 query.source 推定搜索，也不采集搜索词。场景定义依据[微信官方类型仓库](https://github.com/wechat-miniprogram/api-typings/blob/master/types/wx/lib.wx.app.d.ts)，2026-10-18 核对。

首次触达后精确 7×24 小时内归因，首次入口和来源不被后续访问覆盖；到期后首次触达不重置。通过可选 auth.login.growthEntry 关联窗口内新建的活跃账号，旧客户端和老账号不产生新账号归因。建谱成功使用既有 users.firstCreatedFamilyAt（含成功复制创建）；点击、接受任务或失败不计成功。再观察第一份家谱创建后 7×24 小时内是否有非创建者加入，使用现存家谱和既有清理历史事实。

运营 `growth.summary` 仅 operator/super_admin 可调用，输入 startDay/endDay（北京时间首次触达日，最多90天）、source（search/share/unknown/all，默认search），返回截止时刻、采集起点、完整性、窗口成熟状态、期间去重汇总和按首次入口内容分组。建谱率＝窗口内首次建谱新用户/首次触达访客；家人加入比例＝7天内有家人加入的首次家谱/首次建谱新用户。无分母为“—”。新增 defaultEntry 汇总及分组 entryType：仅首次触达类型为 default_example 的队列；分母为加载前取得身份并成功记录的去重访客。加载成功率＝7天内默认模式成功体验示例人数/队列访客；创建点击率＝默认模式点击创建人数/队列访客；加载失败人数按人去重，重试成功可同时出现在成功与失败中。后续明确链接的体验和点击不混入本首屏指标；七天建谱及家人加入仍按原队列归因。后台显示当前来源筛选及窗口暂定提示；没有 entryType 的历史记录不推算为默认入口。原 analytics.summary 定义和界面指标不变。匿名访客不计原“每日新用户”。观察未满标暂定；涉及首个不完整采集日须提示部分数据，不能将无数据解释为完整零值。单集合超过20,000条明确拒绝，要求缩小日期范围。

新增 growth_visitors、growth_events，保存脱敏标识、公开入口、事件日期及关联的内部用户标识，新增可选入口类型与曝光/失败事件，无集合、索引、安全规则或 schema 版本变化；不保存原始 openid、姓名、邀请 token、搜索词或私人家谱正文；明细180天到期由已有保留任务清理。schema v13 的初始化幂等创建集合及 system_config/growth.trackingStartedAt，不覆盖采集起点。新增索引含日期/ID和到期时间/ID；客户端规则继续禁止直接读写。

## 验收与发布后观察

本地运行 `bash scripts/check.sh`；后台构建显式给独立 staging 的 VITE_CLOUDBASE_ENV 并加 --build-admin。专项回归覆盖公开路径、收录规则、数据范围、去重、跨日、归因、测试排除和旧接口鉴权。

staging 按获授权护栏部署 youpuJobs、bootstrap、索引与 deny-all，再部署用户/运营 API 和后台，回读配置、源码、索引、规则和 HTTP 成品。只用虚构示例与测试账号。真机检查清缓存、无账号阅读、登录失败、直达、邀请、老用户路由、示例下架、横竖屏及大字；开发者工具重扫并记录实际编译包字节。没有真机和平台证据时不得标为通过。生产服务端另需当前明确授权。

保持微信平台页面收录开启及每10分钟20次的现有上限。平台专属配置由人工核对。第14天仍无记录时核对线上版本、直达、正文、链接与平台反馈。有收录无访问时优化标题和选题，有访问无建谱时优化内容及创建入口。每两周根据证据选择后续指南，不自动承诺或启用定时任务。主动推送接口首期未接入。
