# 小程序长辈模式与字号

> 文档状态：现行规范；核验日期：2026-10-21。本说明描述当前源码和本地回归。用户已于 2026-10-11 确认 staging 验收完成并授权生产部署；未提供逐设备或参与者测量记录。交付状态见[生产交接](./releases/适老化-生产交接-2026-10-11.md)，此前[客户端交接](./releases/长辈模式入口与启用边界-交接-2026-10-11.md)保留历史结果。

## 入口与偏好

唯一入口为“我的 → 帮助与反馈 → 长辈模式与字号”，显示已开启/未开启状态。“修谱指南”、用户反馈群、阅读设置依次排列，三项共用一整张卡片，以分割线区分；长辈模式说明为“简化操作，调大按钮与字号”。个人资料加载中或失败时仍提供该帮助入口。首页、家庭、图谱更多和隐私页不提供设置入口。新增设置页后共 30 个注册页面；此前 29 页及日期共用组件已接入阅读样式。

首次默认普通模式、跟随微信字号。手动可选标准、125%、150%、200%，覆盖跟随值；关闭模式保留字号选择并继续生效，其他交互恢复普通模式。“恢复默认”关闭模式并恢复跟随。使用 `wx.getAppBaseInfo().fontSizeScaleFactor`，缺失、异常或无效值按 1 回退；不叠加系统根字号。

设置页的“长辈模式”标题与开关处于同一横向布局，开关固定在右侧、不缩小；说明位于下方。大字时标题可在左侧换行，保持开关可见。

本机保存键为 `youpu_reading_preference_v1`，只含 `elderMode` 和 `fontScale`。不上传年龄或阅读偏好，不改变家谱内容、角色、会员或他人的显示方式。读存储失败用默认值，写存储失败本次仍生效，设置页明确提示无法保证重启保留。测试身份重置恢复默认；清理普通临时文件保留阅读设置。

普通正文基准 16 逻辑 px，长辈正文基准 20px、重要辅助文字至少 18px，再乘跟随或手动倍率；长辈 200% 正文为 40px。字体采用逻辑 px 变量，不随屏幕 rpx 换算缩小。跟随微信缩小档允许按用户选择显示较小文字；应用内手动档位从标准开始。

## 页面与图谱

- 普通模式保留原按钮尺寸和布局，大字时做防裁切所需的换行、撑高和底栏重排；长辈主操作目标 60px，并启用简化工具和单列区块。原生 TabBar 保留，未选中文字加深；原生控件实际热区和宿主字号仍需真机核验。
- 真实与示例家谱普通／长辈模式统一六项独立工具：放大、缩小、全图、横／竖屏、设置、清屏；移除首页专用找家人、看清姓名及更多面板，其他页面找人入口不变。长辈热区至少 60px，字号随偏好；优先单列，高度不足多列、极低窗口工具区滚动，不缩小或合并。示例底部常驻创建和切换入口，字号较大时按钮整体换行，横屏保留底栏、清屏隐藏并恢复；极低窗口头部和底栏限高可滚动，保留画布空间。顶部统一查看方式与导出入口，窗口不足 600px 时大字号首行查看方式，后续导出和邀请优先等宽并排；窄屏不足时按钮整体换行。窗口至少 600px 时三项保持一行，查看方式占剩余空间、长名称单行省略，保留放大字号和点击区域；“导出”“邀请家人”文字始终完整单行。普通模式首次选中／再次打开人物抽屉、关系手势与流光保留，姓名排列、配色和收起偏好不被覆盖。
- 长辈点击人物直接打开原人物抽屉并保留关系高亮；权限和广告查询沿用原逻辑。成员列表提供找人及详情入口，示例通过顶部查看方式的人物搜索选择视角；详情直接关系可跳转，长辈管理员不依赖侧滑即可移除关系，仍需原确认。
- 图谱布局可选 `contentScale` 默认 1，仅统一缩放已算出的节点、连线、交叉标记和画布几何；保持关系、排序和默认调用。图内字体与尺寸采用同一倍率，姓名首屏目标为普通 16px、长辈 20px 再乘字号倍率。
- 改字号时优先保持选中人物的屏幕位置；未选中则保持最近中心人物。只在倍率变化时重算，不在拖动/缩放时重算。清屏退出在长辈模式有可见文字，长辈关闭关系流光但保留关系高亮、加载及保存反馈。
- 图谱几何探针仍测量原始 100rpx，不随阅读倍率放大。图片导出重新调用默认布局，PDF 使用默认可选参数，均不因本机字号改变成品。

## 表单、广告与无障碍

添加/编辑成员大字底栏实测高度为正文留空间，按钮上下排列；输入、日期及选择项随字体撑高。长辈模式的姓名提供可见错误与聚焦，成功及失败结果持续显示，用户主动返回；普通模式保留原错误提示，添加保存成功后 600ms 返回、编辑保存成功后 700ms 返回，头像失败仍留页重试。两种模式失败均保留输入和重试机制，离页清理返回计时，避免跳走下一页。保存并继续添加仍恢复空表单，长辈模式保留上一项结果。公农历、闰月、部分日期、关系摘要、未保存提醒、去重和角色审核规则保留。

原生广告展示、关闭、会员免广告与计时规则保持。普通标准字号保留原操作区与开屏空间分配；放大字号时允许必要重排，并按实测按钮区高度分配内容，长辈模式额外提供大按钮。不裁切或拉伸原生广告素材，不新增平台广告配置。保留广告的长辈模式不宣称为无广告认证适老版。日期滚轮在普通标准字号下保留 88rpx/宽屏 44px 选中行，大字或长辈模式按正文尺寸同步放大滚轮和选中行。

点击组件补按钮语义，原生字段补阅读名称，选择项补选中说明；图谱装饰线及隐藏侧滑操作不参与读屏。以列表、详情和表单完成核心任务作为读屏验收路径；仅增加 ARIA 标签不证明 VoiceOver/TalkBack 焦点或朗读顺序已验收。

## 维护与验收

字号声明使用 `--reading-font-*` 或正文/说明变量，避免另写固定 rpx 小字。图谱内部尺寸使用 `--graph-content-scale`，不得给几何探针加倍率。改样式后运行 `node scripts/generate-large-screen-styles.mjs`；改共享图谱逻辑后运行 `node scripts/package-pdf-layout.mjs`，同步 PDF 依赖和指纹，不能手改副本。

统一执行 `bash scripts/check.sh`，专项见[阅读回归](../tests/reading-preference.test.js)及[启用边界回归](../tests/reading-mode-boundary.test.js)。原生开发者工具编译器可离线验证 WXML/WXS/WXSS，但不能证明视觉、支付、广告及读屏实际效果。

staging develop 验收入口：我的 → 帮助与反馈 → 长辈模式与字号。使用虚构资料，不以 trial/release 代替 staging 验收。检查 320/375/430px 手机、横屏与键盘、iPad/电脑、600/1024px 边界、标准至 200%、长姓名/复杂关系/500 人、保存与审批、支付和广告原规则。VoiceOver/TalkBack 及 5–8 位自愿长辈试用需独立记录；每项核心任务至少 80% 无主持人代操作完成，失败必须定位处理。
